# AWS Startpaket
Filerna här är startpunkten för labberna i V46-V48. 
Kopiera dem till ditt kursrepo.

Sök på typens namn, till exempel AWS::EC2::Subnet.

Färdiga lösningar ingår inte. 
Kommentarerna i filerna är på engelska.
